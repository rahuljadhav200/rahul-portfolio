RAHUL JADHAV — DATA ANALYST PORTFOLIO

HOW TO RUN
1. Extract Rahul-Portfolio.zip.
2. Open the extracted Rahul-Portfolio folder in Visual Studio Code.
3. Make sure index.html, style.css, script.js, Rahul_Jadhav_Resume.pdf, and assets/profile.png stay in their current relative locations.
4. Open index.html in a browser. For easier development, use the VS Code Live Server extension and choose "Open with Live Server".

HOW TO UPDATE
- Replace assets/profile.png to change the profile photo (keep the same filename).
- Replace Rahul_Jadhav_Resume.pdf to update the downloadable resume (keep the same filename).
- Edit text in index.html.
- Edit colors, spacing, and layout in style.css.
- Edit interactions in script.js.

BEFORE PUBLISHING
- Add a real screenshot of the Blinkit dashboard if you want it shown instead of the illustrative mockup.
- Add verified project findings and any certification links you have.
- Review the experience section and confirm all dates/details are accurate.
- Your LinkedIn URL was not provided, so no LinkedIn button is included.
- The contact section uses your email and GitHub profile.
- The contact method is a mailto link, not a backend-powered form.
